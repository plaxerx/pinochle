# Reference art

Source material for every sprite in `assets/`. Work from these files rather than drawing from
scratch, so new art keeps vanilla's shapes and palette.

| File | What it is |
|---|---|
| `vanilla_j_ice_cream_1x.png` | Ice Cream joker, cell (4,10) of vanilla `Jokers.png` |
| `vanilla_cone_isolated_1x.png` | The same cone with the card background flood-filled away |
| `vanilla_joker_frame_1x.png` | That cell with the art erased — a blank vanilla Joker card |
| `picard_joker_card_1x.png` | The mod icon at full card size, built on that frame |
| `cardsleeves_sleeves_{1x,2x}.png` | CardSleeves' own atlas — the chrome and mini-deck reference |

Detail is reduced by mode-downscaling (most common colour per NxN block), which keeps flat
pixel-art regions intact where area averaging muddies them.
